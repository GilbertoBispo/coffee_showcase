# Coffee Showcase

A clear and responsive web interface built to showcase varieties of Indonesian single-origin specialty coffees in a modern carousel element. Designed with a clean, minimalist SaaS aesthetic, this project explores tactile micro-interactions, fluid spring physics, and modern visual hierarchy.

## ✨ Key Features

- **Fluid Spring Physics:** Powered by Framer Motion for natural inertia, smooth card transitions, and tactile feedback.
- **Multi-Modal Navigation:** Full support for touch/mouse drag gestures, on-screen controls, and keyboard arrow navigation (`←` / `→`).
- **Minimalist Design System:** Built on a crisp neutral canvas (`#FAFAFA`) with subtle glassmorphism, dynamic ambient glows, and `#0EA5E9` accents.
- **Typography & Hierarchy:** Styled with **Plus Jakarta Sans** for clean, modern readability across desktop and mobile viewports.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Font:** Plus Jakarta Sans (`next/font/google`)
